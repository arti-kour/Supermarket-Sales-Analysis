# Supermarket Sales Analysis Using Microsoft Excel

## Project Overview
This beginner-level data analytics project explores 1,000 simulated supermarket transactions using Microsoft Excel. The aim was to understand sales performance, customer purchasing patterns, and monthly revenue trends.

## Tools Used
- Microsoft Excel
- Excel formulas and functions
- Filters and data sorting
- PivotTables and PivotCharts
- Charts and conditional formatting

## Work Performed
- Checked data for missing values, duplicate invoice IDs, and revenue calculation inconsistencies.
- Calculated key performance indicators, including total revenue, transactions, units sold, average transaction value, and average customer rating.
- Analysed revenue by branch, product line, customer type, and payment method.
- Examined monthly revenue trends using PivotTables and charts.

## Key Findings
- Fashion accessories generated the highest revenue among product lines.
- Food and beverages generated the lowest revenue among product lines.
- Health and beauty had the highest quantity sold.
- Credit cards were the most frequently used payment method; cash was the least frequently used.
- Normal customers generated slightly more revenue than member customers.
- January had the highest monthly revenue, February the lowest, followed by a partial recovery in March.

## Data Quality Checks
- No missing cells were found in the checked source data.
- No duplicate invoice IDs were found.
- Revenue calculations matched the expected totals in the dataset.

## Dataset Note
The dataset contains 1,000 simulated transactions created for learning and portfolio practice. It does not represent actual sales from a real supermarket.

## Project Files
The Excel workbook includes raw data, data quality checks, KPI summaries, and separate analyses of branches, products, payment methods, customer types, and monthly revenue.

## What I Learned
I practised checking data quality, using Excel formulas, building PivotTables and PivotCharts, calculating KPIs, and communicating findings through charts and summaries.
